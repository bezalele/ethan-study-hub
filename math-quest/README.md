# Ethan Math Quest (Grade 9)

Interactive study guide and exercise hub for Ethan's Grade 9 math course.

## Run

Open `index.html` in a browser.

## Features

- Study mode with concept snapshots and big-picture ideas
- Exercise mode with story-based problems, hints, and step-by-step solutions
- Progress tracking by topic + overall dashboard
- Confidence scoring and streak tracking
- Difficulty selector and generated extra practice

## Notes

- Progress is stored in browser localStorage under a dedicated key so it does not interfere with any other course content.
