# Real-life Biology image sources

These files are stored locally in this repository under `biology/assets/real-life/`. The study site does **not** hotlink these images.

The source collection is the OpenStax Biology GitHub mirror `philschatz/biology-book`, which states: “Copyright 2014 OpenStax College. This work is licensed under a Creative Commons Attribution 3.0 Unported License.”
